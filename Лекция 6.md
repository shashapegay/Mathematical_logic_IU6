# Не импликативные (прикладные) предваренные нормальные формы

Этапы получения:

1. Исключение импликации:
$$
A → B = \lnot A \lor B = \lnot(A \land \lnot B)
$$
	Эквивалентность сводят к → и тоже исключают:
$$
A \equiv B = (A → B) \land (B → A) = ...
$$
2. Переименование (если необходимо) связанных переменных так, чтобы одна и та же переменная не входила и связано, и свободно:
$$
\exists y \forall x A(x,y) \lor B(y) \land \exists x C(x) = \exists z \forall x A(x, z) \lor B(y) \land \exists x C(x) 
$$
	Новое имя берется такое, которое отсутствует в той части формы, где подлежащая переменная связана.
3. Разделение (если необходимо) связанных переменных. Достигается отсутствием кратного связывания одной и той же переменной.
4. Удаление квантификаций, в области действия которых нет квантифицированной переменной (**элиминация**).
5. Протаскивание отрицаний (спуск отрицаний до уровня предикатов).
6. Смещение кванторов влево но основании лемм:
	1. $\forall x A \land \forall x B <=> \forall x (A \land B)$
	2. $(\forall x A) \land B <=> \forall x (A \land B) (B \ \text{не содержит} \ x)$
	3. $A \land (\forall x B) <=> \forall x (A \land B) (A \ \text{не содержит} \ x)$
	4. $(\exists x A) \land B <=> \exists x (A \land B) (B \ \text{не содержит} \ x)$
	5. $A \land (\exists x B) <=> \exists x (A \land B) (A \ \text{не содержит} \ x)$

Принимается, что для $\lor$ применимы аналогичные леммы.

# Markdown

Лекции в данной папке изначально писались в [Obsidian](https://obsidian.softstribe.net/). В связи с этим в некоторых файлах есть ошибки, делающие формулы нечитаемыми. Основная причина в том, что `Markdown` сам по себе не имеет встроенного, универсального стандарта для отображения математических формул. Разные программы по-своему интерпретируют синтаксис.

Лучше пользуйтесь папкой `/PDF`. Если при конвертировании из `.md` в `.pdf` возникли проблемы, делающие файл нечитаемым, можете писать мне в [телеграм](https://t.me/shasha_pegai).

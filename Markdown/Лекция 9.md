# Как исчислять значения нечетких операций

$$
\begin{align}
& \mu_{\lnot{\tilde{A}}}(x) = 1 - \mu_\tilde{A}(x) \\
& \mu_{\tilde{A}\land\tilde{B}}(x) = min(\mu_\tilde{A}(x); \mu_\tilde{B}(x)) \\
& \mu_{\tilde{A}\lor\tilde{B}}(x) = max(\mu_\tilde{A}(x); \mu_\tilde{B}(x))
\end{align}
$$
$-$ логика с **максиминными операциями**.

Правило поглощения в максиминных операциях:

$$
\begin{align}
& \mu_{\tilde{A}\lor\lnot{\tilde{A}}}(x) = max(\mu_\tilde{A}(x); 1 - \mu_\tilde{A}(x)) \\
& \mu_{\tilde{A}\land\lnot{\tilde{A}}}(x) = max(\mu_\tilde{A}(x); 1 - \mu_\tilde{A}(x))
\end{align}
$$

# Обобщение логических операций в нечеткой логике

1. Обобщение конъюнкций ($t$-норма)
	Граничное условие: $\tilde{A} \ t \ 1 = \tilde{A}$
2. Обобщение дизъюнкций ($k$-норма)
	Граничное условие: $\tilde{A} \ k \ 0 = \tilde{A}$

Операции двойственны и связаны законом де Моргана:
$$
\lnot(\tilde{A} \ k \ \tilde{B}) = \lnot\tilde{A} \ t \ \lnot\tilde{B}
$$

# Формулы для оценки обобщенных дизъюнкций и конъюнкций

$$
\mu_{\tilde{A} \ t \ \tilde{B}}(x) = 
\left[
\begin{array}{l}
\ min(\mu_\tilde{A}(x); \ \mu_\tilde{B}(x)) \text{ - классическая форма}\\
\ \mu_\tilde{A}(x) \dot \ \mu_\tilde{B}(x) \text{ - алгебраическое произведение}\\
\ max (\mu_\tilde{A}(x) + \mu_\tilde{B}(x) - 1; \ 0) \text{ - граничное произведение}
\end{array}
\right.
$$
$$
\mu_{\tilde{A} \ k \ \tilde{B}}(x) = 
\left[
\begin{array}{l}
\ max(\mu_\tilde{A}(x); \ \mu_\tilde{B}(x)) \text{ - классическая форма}\\
\ \mu_\tilde{A}(x) + \ \mu_\tilde{B}(x) - \mu_\tilde{A}(x) \dot \ \mu_\tilde{B}(x) \text{ - алгебраическая сумма}\\
\ min (\mu_\tilde{A}(x) + \mu_\tilde{B}(x) - 1; \ 0) \text{ - граничная сумма}
\end{array}
\right.
$$
### Пример

"К вечеру будет довольно пасмурно и не исключено, что будет дождь."

$\tilde{A}$: "пасмурно"
$\tilde{A}$ = $\{(19, 0.2); (20, 0.5); (21, 0.9)\}$ *(множество упорядоченных пар (время; значение функции принадлежности))*

$\tilde{B}$: "дождь"
$\tilde{B}$ = $\{(19, 0.5); (20, 0.7); (21, 0.8)\}$

1. $\mu_{\tilde{A} \ t \ \tilde{B}}(x) = \{(19, 0.2); (20, 0.5); (21, 0.8)\}$ - по классической форме
2. $\mu_{\tilde{A} \ t \ \tilde{B}}(x) = \{(19, 0.1); (20, 0.35); (21, 0.72)\}$ - по алгебраическому произведению
3. $\mu_{\tilde{A} \ t \ \tilde{B}}(x) = \{(19, 0); (20, 0.2); (21, 0.7)\}$ - по граничной сумме

# Формула обобщенной нечеткой импликации

$$
\mu_{\tilde{A} \ → \ \tilde{B}}(x) = 
\left[
\begin{array}{l}
\ max(min(\mu_\tilde{A}(x); \ \mu_\tilde{B}(x)); \ 1 - \mu_\tilde{A}(x)) - \text{формула Заде} \\
\ max(1 - \mu_\tilde{A}(x); \ \mu_\tilde{B}(x)) - \text{формула Гёделя} \\
\ min(\mu_\tilde{A}(x); \ \mu_\tilde{B}(x)) - \text{формула Мамдани} \\
\ min(1 -\mu_\tilde{A}(x) + \mu_\tilde{B}(x); \ 1) - \text{формула Лукасевича} \\
\ min(\frac{\mu_\tilde{A}(x)}{\mu_\tilde{B}(x)}; \ 1) - \text{формула Гогена} \\
\ min(\mu_\tilde{A}(x) + \mu_\tilde{B}(x); \ 1) - \text{формула граничной суммы} \\
\ max(\mu_\tilde{A}(x) \dot \ \mu_\tilde{B}(x); \ 1 - \mu_\tilde{A}(x)) - \text{формула Н. Вади} \\
\end{array}
\right.
$$

# Нечеткая лингвистическая логика

В основе лежат понятия нечеткого множества и лингвистической переменной. Цель - большее приближение к естественному языку при формализации логических рассуждений.

Используются следующие виды нечетких понятий:

1. количественные;
2. истинностные;
3. понятия категории.

**Лингвистическая переменная** - это переменная, принимающая значения слов и предложений естественного языка. 

Лингвистическая переменная задается 5-местным кортежем:
$$
<X, \ T(X), \ U, \ G, \ [M]>, \ \text{ где}
$$
$X$ - название лингвистической переменной;
$T(X)$ - множество его лингвистических значений;
$U$ - базовое множество (универсум);
$G$ - синтаксические правила, порождающие множество значений лингвистической переменной (функции принадлежности нечетким функциям);
$[M]$(опционально) - семантические правила, которые каждому значению ставят в соответствие смысл, применяются для расширения $T(X)$.

### Пример

$X$ - "возраст";
$T(X)$ - {"очень молодой", "молодой", "средний", "почтенный"};
$U$ - $[0; \ 120]$;
$G$ можно задать как графически, так и аналитически. Пример графического обозначения:

![[lecture_9_pic_2.png]]$G = \{\mu_\tilde{A_1} ; \mu_\tilde{A_2}; \mu_\tilde{A_3}; \mu_\tilde{A_4} \}$
$(x = 21)$ есть значение "очень молодой" с $\mu_\tilde{A_1}(21) = 0.1$
$(x = 21)$ есть значение "молодой" с $\mu_\tilde{A_2}(21) = 0.75$

Таким образом, лингвистическое множество переменной задает множество нечетких множеств, каждое из которых со своей функцией принадлежности отвечает за степень истинности одного лингвистического значения.

Нечеткая логика, построенная на лингвистических переменных, называется **нечеткой в широком смысле**, в отличие от ранее рассмотренной логики, которую называют **нечеткой в узком смысле**.

# Нечеткий логический вывод

Под нечетким логическим выводом понимают получение заключения в виде нечеткого множества, полученного на основе базы нечетких правил с выполнением нечетких логических операций по заданным значениям входных переменных.

# Этапы построения нечеткого логического вывода

1. Сформулировать на естественном языке импликативные правила (ЕСЛИ-ТО), отражающие закономерности заданной предметной области.
2. Выделить из правил входные и выходные лингвистические переменные, определить их значения $T(X_i)$ и сопоставить значениям нечеткие множества.
3. Записать нечеткие правила формализовано.
4. Проверить базу правил на полноту (2 критерия, см. ниже).
5. Выполнить последовательно фаззификацию, агрегацию, дефаззификацию.

# Критерии полноты базы нечетких логических правил

1. Для каждого значения выходной лингвистической переменной существует хотя бы одно правило.
2. Для каждого значения каждой входной лингвистической переменной имеется хотя бы одно правило, в котором это значение используется в качестве посылки вывода.
(Принято, что на 1 правило приходится не более 1 импликации)

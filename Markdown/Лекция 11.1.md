# Исследование операций

Применение математических количественных методов для обоснования принятия решения во всех областях деятельности принято называть **исследованием операций**.

**Операция** - всякое мероприятие системы действий, объединенных общей целью и направленная на достижение конкретного результата. Операция есть управляемая категория. 

Всякий набор зависящих от нас параметров называется **решением**. Решение считается оптимальным, если по тем или иным критериям оно лучше остальных. Иногда (редко) удается достигнуть единственного оптимального решения.

Параметры, образующие в своей совокупности решения, называют **элементами решения** (числа, вектора, матрицы, физические величины).

В каждом случае можно определить **критерий эффективности** (он же **показатель эффективности** или **целевая функция**). 

Совокупность элементов решения $x_1, x_2, ..., x_n$ иногда объединяют в $x \in X$, где $X$ - множество всех решений.

Если область допустимых решений не ограничена сверху, то $X$ бесконечно для задачи $f → max$. 

Если область допустимых решений не ограничена снизу, то $X$ бесконечно для задачи $f → min$.

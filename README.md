# Темы лекций

1. Основные понятия. Логическое следование и эквивалентность. Подстановка и замена.
2. Определение формальной теории. Понятие выводимости и вывода и их свойства. Непротиворечивость и разрешимость формальной теории.
3. Общие замечания теории L. Правила резолюции и метод резолюций в логике высказываний. Стратегии резольвирования.
4. Логика предикатов. Свободное и связное вхождение переменных. Форма Бэкуса-Наура для теории L.
5. Формальная теория K. Непротиворечивость и полнота ИППП. Правила переименования переменных. ПНФ.
6. Не импликативные ПНФ.
7. Сколемизация. Клаузальная форма. Метод резолюций в логике предикатов первого порядка.
8. Нечеткая логика.
9. Исчисление значений нечетких операций. Обобщение логических операций. Нечеткий логический вывод.
